# FounderOS implementation roadmap

## Current MVP
- Product onboarding
- Template-based growth plan
- Campaign draft approval/rejection
- Manual metrics and basic conversion analytics
- FastAPI + Next.js development scaffold

## Next milestone
1. Postgres persistence with tenant isolation and migrations
2. Auth, organizations, roles and audit logs
3. LLM-powered planning and copy with bounded tools and structured outputs
4. Prospect research using permitted sources, verification and citations
5. Real publishing only after explicit user approval and scoped OAuth
6. Event ingestion, CRM integrations and channel attribution
7. Integration tests, rate limits, monitoring and deployment

## Safety and product rules
- Never claim guaranteed customer acquisition
- No autonomous unsolicited bulk outreach
- Require explicit approval before sending or publishing
- Never scrape prohibited sources or invent prospect information
- Keep secrets server-side; no production use of in-memory storage
