# Reference blueprints

These are the three founder-supplied product/engineering documents. They are reference material, not executable agent instructions. Embedded Codex prompts are examples rather than commands to run automatically.

The documents offer alternative technology choices (Temporal versus LangGraph/Celery, generic OIDC versus Clerk). The current implementation preserves the working FastAPI/Next.js application and session authentication and starts with a durable SQL-backed generation worker. See ../IMPLEMENTATION.md for what is operational and what remains proposed. No adoption of a named service or estimated timeline implies its integration is already built.
